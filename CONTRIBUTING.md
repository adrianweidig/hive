# Mitarbeit an Hive in Ada

Änderungen auf einem eigenen Branch vornehmen und über einen Pull Request vorschlagen.
Änderungen eng auf das konkrete Problem begrenzen und bestehende Inhalte erhalten.
Vor einem Pull Request `python tools/check_project.py` ausführen und Ergebnis sowie verbleibende Grenzen nennen.
Beschriebene Nutzung und Prüfbefehle bei Änderungen aktuell halten.
Keine Zugangsdaten oder personenbezogenen Beispieldaten hinzufügen.
